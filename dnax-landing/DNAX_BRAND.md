# DNA-X Brand (v0.2 · 2026-10-10)

**Palette decision (Chris, 2026-10-10):** DNA-X keeps its original **navy + orange** palette. It was DNA-X's look all along. Only the token prefix changes (`--now-*` → `--dnax-*`); the colours and roles don't. The violet/teal proposal (v0.1) is retired.

**Type:** Blinker for display, Barlow for body.

## Core brand
| Token | Hex | Role |
|---|---|---|
| `--dnax-navy` | `#1A1A2E` | Primary brand: hero background, headings, body text |
| `--dnax-deep-navy` | `#080808` | Deepest tone: footer, high-contrast panels |
| `--dnax-orange` | `#E84C1E` | Accent: CTAs, links, eyebrow text, **the X in DNAˣ** |
| `--dnax-orange-dk` | `#B83B17` | Hover state on orange buttons and links |
| `--dnax-orange-light` | `#FF6B3D` | Reserved: gradients, glows, hover accents |

## Relationship to PsikiQ
PsikiQ is gold on a warm void (Oswald / Chakra Petch). DNA-X is orange on navy (Blinker / Barlow). The relationship is carried by the endorsement ("A PsikiQ Solutions company"), not by shared colour.
