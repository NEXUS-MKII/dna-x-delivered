Asset-mechanics diagnostic for hero video scripts, 45–75 second LinkedIn videos, and direct-to-camera content.

Voice Layer Note
This is an asset-mechanics rubric. Voice integrity is NOT scored here — it is handled by pairing the Voice Parameter Block (Encoder Pro / Encoder Lite) at score time. Run voice gate separately. This rubric scores ONLY whether the asset works structurally as the asset type it claims to be.

What this is
A scoring tool to predict whether a video script will stop the scroll, hold attention through the framework, and land the CTA — vs look fine on paper and die on camera.
Scope: 45–75 second scripts, direct-to-camera. Score the script BEFORE shoot. Re-score after recording with delivery overlay.

Core Principle
A video script does three jobs:
Hooks in the first 5 seconds (no setup, no warming up)
Sounds spoken, not written (transcript not essay — short sentences, broken rhythm, contractions)
Lands the CTA in one clean line — earned by the framework
A script that reads well silently can still die when spoken. The single most important test: read the whole thing out loud. If you stumble, the watcher will tune out.

Gates
PASS (70+): shoot it.
HOLD (60–69): good bones, weak hook or weak landing. Run upgrade pass before recording.
KILL (<60): reads written, hook is setup, or no clean framework. Rewrite from hook using UMDB Phase 6.

Asset Standard (must contain)
Per 16-min Runbook Section C + UMDB Phase 6:
Hook lands in first 5 seconds — no "Hey everyone, today I want to talk about..."
Pattern: Hook → Problem → Framework → Next Step
Length 45–75 seconds (110–180 words at conversational pace)
Spoken rhythm — short sentences, broken pace, occasional fragment
Contractions (don’t, it’s, that’s)
ONE CTA, plain English, last line
If the script reads as written, score caps at 65.

Copy/Paste Prompt
I am going to give you a 45–75 second LinkedIn video script and a description of my business, audience, and offer. Score whether the right person watches past 3 seconds, holds through the framework, and acts on the CTA — or swipes within 2 seconds. Score using the rubric below. Return PASS (70+), HOLD (60-69), or KILL (<60).

STEP 1 — HOOK + SPOKEN RHYTHM (30 pts) — heaviest weight
Cold start hook (0–15):
Provocation, scene, or contrarian claim?
Or warming up? ("Hey everyone, today I want to talk about...")
Would the right person stop in 2 seconds at autoplay-no-audio?
Does it work as captions only?
Spoken rhythm (0–15):
Read out loud — any stumbles?
Short sentences mixed with longer ones, or every sentence the same length?
Contractions present (don’t, it’s, that’s)?
Sounds like talk, not text?

STEP 2 — STRUCTURE (25 pts)
Problem tension (0–10):
Does the watcher feel the cost (time, money, missed opportunity, identity)?
Or does the script jump straight to the framework without earning it?
Framework delivery (0–15):
ONE clean idea, taught well? (Not 5 things — one thing.)
Could the watcher repeat the framework after watching once?
Or is it cluttered with too many parallel concepts?

STEP 3 — CTA + LENGTH (25 pts)
CTA landing (0–15):
Last line? Singular? Plain English?
Earned by the framework, not bolted on?
Matches campaign phase (Soft early / Hard late)?
Length discipline (0–10):
45–75 seconds at conversational pace?
Could anything be cut without losing meaning?

STEP 4 — AUDIENCE LOCK + SHOOTABILITY (20 pts)
Audience lock (0–10):
Right reader hears themselves in the hook?
Specific noun from their world?
Shootability (0–10):
Can this be delivered direct-to-camera without props or visual aids?
B-roll suggestions provided where needed?
On-screen text minimal and specified?

Upgrade Pass (HOLD → PASS)
Hook (+5 to +10): Cut any setup. Start cold. Open with scene, contrarian claim, or specific moment. Read first 2 lines aloud — would you stop scrolling?
Spoken rhythm (+3 to +5): Break any sentence longer than 15 words. Replace "do not" with "don’t". Vary sentence length deliberately.
Framework (+3 to +5): If 5 ideas, cut to 3. Cut to 2 if you can. Make each part observable, not abstract.
CTA (+3 to +5): Last line. Clean. Singular. Plain-English next step. No "and also...".

Pre-Shoot Checklist
Run this BEFORE pressing record:
Read whole script out loud — any stumbles, fix now
Hook test — would it stop you on a phone at 7am?
Time it — 45–75 seconds at conversational pace?
CTA test — singular, last line, plain English?
Caption test — would the script work on a phone with no audio? (Captions need to carry it.)

Common Failure Modes
Setup hook ("Hey everyone, today I want to talk about...")
Reads written — long sentences, no contractions
Framework crammed with 5 ideas instead of one taught well
Vague CTA ("Reach out if you want to learn more")
Stacked CTA ("Comment, DM, link in bio, book a call")
Length wrong — under 30s feels rushed, over 90s loses attention
